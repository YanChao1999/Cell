Why not a generic sandbox?

Cloud VMs and hosted sandboxes solve “run untrusted code.” Cell is shaped for the agent loop: short-lived workspaces, warm caches, and a control plane you own.

Workspace dies · cache lives

Each Cell is disposable. Git mirrors and package caches stay on the worker so the next create is warm — without sharing mutable state between agents.

Fail closed by default

Unknown network modes and unfinished runtimes reject. Allowlist egress is enforced in the runtime path, not bolted on later.

Self-hosted control plane

Run on your machines, behind your proxy. Multi-worker place, Bearer worker auth, and cross-node cache pull — without sending agent traffic to a third-party sandbox SaaS.

What ships today

Docker sandbox + allowlist egress, template setup on create, celld control/worker modes, Compose mini-cluster, Python SDK, and sticky exec across workers.
