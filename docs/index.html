# agent loop
$ cell create --env go-1.23
cell_id=… worker=worker-a
$ cell exec go test ./...
exit 0
$ cell destroy
caches warm · workspace gone

What ships today

Control plane + workers, Docker sandbox with allowlist egress, setup on create, multi-node compose with Bearer worker auth and cross-node cache pull.

Disposable Cells

Workspaces die with the Cell. Git mirrors and package caches stay warm for the next run.

Fail-closed isolation

Unknown network modes and unfinished runtimes reject — they do not silently open the host.

Agent-shaped API

HTTP + Python SDK: create, exec, run, destroy — sticky placement across a worker cluster.
